# thickAPI — map

Local Rust daemon: subscription-backed coding agents (Claude, Grok, agy, Cursor, Codex) as one OpenAI-compatible model API. Thin `POST /v1/chat/completions` is the main surface; the thick `/v1/agent/turn` is frozen. Contract: `SPEC.md` only.

## Go here for

| Task | Read |
|---|---|
| What it is, install, use | `README.md` |
| Orientation, rules, task map for agents | `AGENTS.md` |
| Full contract | `SPEC.md` |
| Chose-X-not-Y | `DECISIONS.md` |
| Now / what's next | `STATE.md` (local, gitignored; if missing, GitHub issues) |
| Change it | `crates/`; tests in each crate's `tests/` and `fixtures/` |

## Folders

| Path | What |
|---|---|
| `crates/thickapi-core/` | types, config, thin adapters (`src/thin/`), engine, enforce, router, store, trust |
| `crates/thickapi-api/` | axum HTTP surface |
| `crates/thickapi-cli/` | `thickapi` binary and `capture` tooling |
| `configs/` | examples copied to `~/.thickapi` on first `serve` |
| `fixtures/` | redacted wire captures `fixtures/<vendor>/<version>/` and stream replays |
| `extensions/pi-thin/` | optional Pi extension |
| `scripts/` | `verify-all.ts`; live-daemon smoke scripts (not CI) |
| `.github/workflows/` | CI on hosted `windows-latest`; `just gate` is the local twin |

## Standing rules

- `SPEC.md` is the single source of truth. No separate architecture docs.
- The rules in `AGENTS.md` apply to every change.
- The queue is GitHub issues.
- **STATE.md tidy:** rewrite the whole file at session end; never append. Only *now* and at most three *next* actions. Missing is fine.
- Product briefs do not edit this file or `DECISIONS.md`.
